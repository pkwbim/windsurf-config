## 將使用者故事添加到待辦清單

### 1. 詢問故事詳情
- 你想要添加什麼功能？
- 使用者是誰？
- 目標是什麼？

### 2. 格式化為使用者故事
// turbo
```bash
# 添加到 _planning/01_backlog.md
```

使用此格式：
```markdown
### Story-[ID] ([分類]): **身為[使用者]，我想要[功能]，以便[價值/目標]**。

[其它相關訊息，若無則寫「無其它資訊」]

```

### 3. 附加到待辦清單
// turbo
```bash
# 添加到 01_backlog.md 中的適當優先級部分
# 分配下一個可用的 ID 號
```

## 範例

```markdown
### Story-001 (聊天): **身為使用者，我想要發送文字訊息給 Agent，並且看到訊息出現在對話列表，這樣我才能開始互動。**

打文字給 Agent ， Agent 若回 Markdown ，則要轉成人類好讀的風格，而不是直接輸出 Markdown。

### Story-002 (歷史記錄): **身為使用者，我想要重新打開 App 時看到之前的對話紀錄，以免遺忘之前的討論。**

無其它資訊
```

## 注意事項
- 保持簡潔扼要
- 使用標準使用者故事格式
- 專注於做什麼，而不是如何做
- 不需要技術細節
- 通知使用者下一步是 /plan 命令來做規劃
- 這個步驟做完就不要再繼續下去，一定要停下來。
